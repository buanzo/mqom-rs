# Public roadmap

This roadmap reports public engineering milestones without exposing private
stewardship material.

## M0: public foundation — complete

- Repository policy, continuous integration, and security posture.
- Fixed v2.1.1 parameter constants and strict public encodings.
- Portable GF(16) and SHAKE128 foundations.
- Separately checked-out, commit-pinned upstream C oracle.

## M1: native verification — complete

- Implement the portable GF(256^2) extension field, cross-field multiplication,
  and canonical little-endian encodings. **Complete.**
- Implement the AES-based PRG, packed MQ equation expansion, and triangular
  matrix operations. **Complete.**
- Implement transcript reconstruction, commitments, opening checks, and
  verification for `MQOM2-L1-gf16-short-r5`. **Complete.**
- Verify all 100 signatures generated by the official v2.1.1 KAT tool.
  **Complete.**

## M2: complete first profile

- Implement caller-randomized key generation and signing.
- Reproduce the complete official KAT byte-for-byte.
- Have upstream `kat_check` accept Rust-generated KAT responses.

## M3: hardening and 0.1.0

- Add parser/verifier fuzzing, negative tests, memory and timing review, and
  representative `no_std` target checks.
- Document the stable high-level API and publish the first crates.io release.
- Continue to label the crate experimental and unaudited.

Additional parameter sets and upstream-version migrations are out of scope
until the first profile is complete.
