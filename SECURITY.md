# Security policy

`mqom-rs` is incomplete research software. No released revision is currently
approved for sensitive or production use, and no independent security audit is
claimed.

Please report suspected vulnerabilities through GitHub private vulnerability
reporting for this repository. Include the affected commit, parameter set,
reproduction details, and whether the report may involve secret-dependent
timing or memory behavior. Do not include real secrets or production data.

Public compatibility bugs that have no security impact may be filed as normal
issues.
